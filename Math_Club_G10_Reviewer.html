Law of Cosines — Oblique Triangles

An oblique triangle has no 90° angle — it's either acute (all angles < 90°) or obtuse (one angle > 90°). The Law of Cosines solves for missing sides or angles.

a² = b² + c² − 2bc·cos A
b² = a² + c² − 2ac·cos B
c² = a² + b² − 2ab·cos C

Lowercase sides sit opposite their matching uppercase angle: A↔a, B↔b, C↔c.

When to use it

SAS know two sides + the angle between them → find the missing side.

SSS know all three sides → find a missing angle.

Quadratic Inequalities — Two Variables

Forms: y > ax²+bx+c, y ≥ …, y < …, y ≤ … (a ≠ 0). The solution is a shaded region, not just a curve.

Region Shader

Set a, b, c and the symbol — the boundary and shaded region update live.

—vertex
—boundary
—(0,0) test

4-step procedure

1. Find the vertex h = −b/2a, plug in for k, plus x- and y-intercepts.
2. Draw the boundary: dashed for strict (< >), solid for non-strict (≤ ≥).
3. Pick a test point — usually (0,0) — plug into the inequality.
4. Shade the region where the test point makes the inequality true.

Shortcut: y > / y ≥ → shade above/inside an upward parabola (outside a downward one). y < / y ≤ → shade below/outside an upward parabola (inside a downward one).

Measures of Position

Quartiles (4 parts), deciles (10 parts), and percentiles (100 parts) all tell you where a value sits in an ordered dataset — not a percent score.

Quartiles (Q)

Qk = k(n+1)/4

Q1=25% below · Q2=median · Q3=75% below

Deciles (D)

Dk = k(n+1)/10

D1…D9, splits data into 10 groups. D5 = median.

Percentiles (P)

Pk = k(n+1)/100

P1…P99. P25=Q1, P50=Median, P75=Q3.

Interpolating a decimal position

Value = (Larger − Smaller) × decimal + Smaller

e.g. data 5,8,12,15,18,20,24,27,30,35 → Q1 position = 2.75 → smaller=8, larger=12, decimal=0.75 → Q1 = (12−8)(0.75)+8 = 11.

Reading a percentile: a student at the 80th percentile scored at or above ~80% of the group — that's not the same as scoring 80% on the test.

Box-and-Whisker Plots & Cumulative Frequency

The five-number summary

Minimum · Q1 · Median (Q2) · Q3 · Maximum

  • Left whisker → minimum to Q1
  • Box → Q1 to Q3 (the middle 50%)
  • Line inside box → median
  • Right whisker → Q3 to maximum

Interquartile range & outliers

IQR = Q3 − Q1
Lower fence = Q1 − 1.5×IQR
Upper fence = Q3 + 1.5×IQR

Any value beyond the fences is an outlier. Small IQR → tightly grouped middle 50%; large IQR → more spread out. (Use the calculator above — outliers show up automatically.)

Cumulative frequency builder — paste your own data

The last cumulative frequency always equals the total count (n). Plotting these running totals and connecting the points makes a cumulative frequency polygon (ogive) — it shows how many observations sit at or below each value.
